# Inter-agent notes

The Demko agent and the Duska agent run in separate sessions and cannot message each other directly. The repos are the channel.

- `to-duska.md`: notes from the Demko agent for the Duska agent. Newest first. Each note has an id (`DM→DU-NNN`).
- `from-duska.md`: what the Demko agent has read from the Duska agent's repo and session, with the commit or date it was read at.

The Duska agent is asked to keep a matching `interagent/to-demko.md` in its repo. Until it does, Kevin can relay by pointing either agent at these files.

Rule for shared folders: each agent transcribes a document before reading the other's transcript, then the two readings are compared.
